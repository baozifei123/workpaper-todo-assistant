# 底稿未完成助手 · 使用说明

版本：0.3.0  
适用系统：Windows 10 / Windows 11（64 位）  
支持软件：Microsoft Excel、WPS 表格

---

## 1. 这个工具解决什么问题

在 Excel / WPS 表格底稿里，审计程序可能已经写好，但资料还没取得、程序还没实际执行。  
本工具让您：

1. 在表格里选中一条审计程序所在的单元格，按一次热键，把它登记为“未完成事项”；
2. 在清单里集中查看哪些底稿还没完成；
3. 点击“定位底稿”，自动回到对应文件、工作表和单元格；
4. 实际完成后，手动把状态改为“已完成”。

工具只负责**提醒和定位**，不会替您判断审计程序是否真的完成，也不会向底稿写入任何内容。

---

## 2. 启动

双击程序文件夹中的 **`底稿未完成助手.exe`**。

- 程序启动后会显示事项清单窗口。首次启动会先打开三步引导，说明本地数据、热键和练习流程；选择“稍后”可关闭，主窗口的引导提示和“更多 → 新手引导…”仍可再次打开。
- 关闭主窗口时，默认**最小化到系统托盘**，热键仍可继续使用；右键托盘图标可以选择“显示主窗口”“登记最近单元格”“打开数据文件夹”或“退出”。
- 如不想使用托盘，可在“设置”中取消“关闭主窗口时最小化到托盘”。取消后关闭窗口即退出，热键停止。
- 建议以与 Excel/WPS 相同的权限级别运行本工具。例如，表格以管理员身份运行而工具以普通权限运行时，Windows 可能阻止读取。通常三者都以普通权限运行即可。
- 第一次启动如果提示“登记热键不可用”，说明 `Ctrl+Alt+M` 被其他软件占用，请到右上角“设置”里换一个组合键；也可以先切换到表格并选中单元格，再切回本工具点击“登记当前单元格”。
- 程序只允许同时运行一个实例；重复双击会把已运行的窗口调到前面。

### 首次使用引导和练习底稿

首次启动会打开三步引导，说明数据位置和明文属性、当前全局热键是否已注册、如何登记/定位/手动更新状态。可点“稍后”关闭引导，主窗口首次使用提示和“更多 → 新手引导…”仍可重新打开。

引导第二步点击“生成并打开练习底稿”后，程序会在数据目录的 `practice` 子目录生成一份合成练习工作簿，并使用新文件名，**不会覆盖已有练习文件或自动打开真实底稿**。打开后选择 B5 并按显示的热键；练习事项登记后可在提示条点击“撤销”。不要把练习事项留在正式项目清单中。

事项库保存在引导页显示的数据目录中，是 SQLite 明文文件，包含程序文字和文件路径；不会上传，也不会向原底稿写入、保存或覆盖内容。请按事务所资料管理要求保管。
发布包内提供图形化 **`安装程序.exe`** 和 **`底稿未完成助手-0.3.0-安装程序.exe`**（Inno Setup 标准安装包），双击即可安装到 `%LOCALAPPDATA%\Programs\底稿未完成助手`，不需要管理员权限；也提供 PowerShell 安装/卸载脚本和 Inno Setup 6 脚本。安装/卸载说明见 `docs/发布与签名说明.md`。

## 3. 登记一条未完成事项

1. 在 Excel 或 WPS 表格中，选中**一条审计程序所在的单元格**（可以是普通单元格，也可以是合并单元格）。
2. 按 **`Ctrl+Alt+M`**。
3. 右下角出现“已登记”提示，清单中新增一行。

登记时会自动保存：

- 文件完整路径、文件名
- 工作表名称
- 单元格位置（合并单元格会记录合并区域）
- 单元格当时的文字内容（用于以后核对位置）
- 登记时间、来源软件（Excel / WPS）
- 文件指纹（卷序列号和文件索引，用于改名后的重复提示和重新关联核对）

### 撤销刚登记的事项

登记成功的提示条会显示项目、文件名、工作表和单元格，并提供 **“撤销”** 和 **“查看事项”** 两个入口；默认显示约 6 秒。  
如果刚选错单元格，点“撤销”即可删除；如果该事项已经被修改，工具不会删除，请到详情中确认。点“查看事项”会打开该事项详情。

### 登记到哪个项目

窗口顶部有“登记到项目”下拉框。新登记的事项会归入该项目；不填时归入“未分类”。  
如果“未分类”且启用了“按底稿文件夹自动建议项目”，工具会用底稿所在文件夹名作为项目建议；遇到“底稿/工作底稿/审计底稿/资料”等通用文件夹时，会向上取一层项目名。  
项目名称可以随时在“事项详情”里修改，也可以在顶部下拉框中输入新项目名。

### 什么情况下会拒绝登记

工具不会“猜”一个位置，遇到以下情况会明确提示，不登记：

- 当前选择了多个单元格（请只选一个程序单元格）；
- 单元格为空或没有可读取的文字；
- 当前工作簿是未保存的新工作簿（请先保存文件）；
- 当前是 Excel 加载项工作簿（如 .xla / .xlam）；
- 当前文件是云文档链接（请使用本机或共享文件夹中的文件）；
- 当前窗口不是 Excel / WPS 表格，或程序正忙、有对话框未关闭。

### 重复登记

如果同一文件、同一工作表、同一单元格已经有一条“未完成 / 等待资料 / 进行中”的事项，工具会提示“该位置已登记”，您可以选择：

- **查看现有事项**：跳到已登记的那一条并打开详情；
- **更新现有事项**：用当前单元格内容更新内容快照，并打开详情补充资料；
- **仍然新增**：同一位置再建一条（一般不建议）；
- **取消**。

文件改名后，如果文件指纹和位置仍匹配，工具也会提示可能重复。

## 4. 查看和回到未完成事项

### 清单

清单默认显示“待办”（未完成、等待资料、进行中），可以按状态、项目、账龄筛选，也可以按程序内容、文件、工作表、单元格、缺失资料、负责人、备注搜索。

- **快捷视图**：选择“待办”“待跟进”“无人负责”或“等待>7天”；也可选“自定义”组合普通筛选。
- **清除筛选**：一键重置快捷视图、状态、项目、账龄、归档开关和搜索词。
- **等待排序**：点击“等待”列标题切换等待天数升序/降序；只改变显示顺序，不改变状态或日期。
- **账龄**：可筛选“等待>7天”“等待>30天”；等待天数按索取日期或进入等待状态的日期计算。
- **含已归档**：默认不显示已归档项目；勾选后可查看。
- **多选**：按住 `Ctrl` 或 `Shift` 选择多条，或用 `Ctrl+A` 全选，然后批量改状态、改项目或删除。
- **详情预览**：清单下方显示选中事项的完整程序、位置、缺失资料、等待天数、备注和时间；多选时显示第一条并提示已选条数。

状态颜色：

- 未完成：红色
- 等待资料：橙色
- 进行中：蓝色
- 已完成：灰色

### 一键定位

选中一行后，任选一种方式：

- 点击工具栏的 **“定位底稿”**；
- **双击**该行；
- 按 **`Ctrl+L`**。

工具会：

1. 如果文件已经打开，切换到对应工作簿和工作表；
2. 如果文件没打开，用原来使用的软件打开它；
3. 选中登记的单元格，并把窗口切到前面。

工具**不会保存、覆盖或关闭**您已经打开的底稿，也不会修改单元格内容。

### 内容变化与文件移动

- 如果登记位置的内容和登记时不一致，会弹出对比窗口，您可以选择“仍然定位”“更新快照并定位”或“取消”。
- 如果文件被移动或改名，重新关联向导会同时显示原路径、目标路径、工作表、单元格和登记快照；请人工核对目标文件。文件指纹不同或无法读取时会明确提示系统无法确认版本，由您决定是否继续核对。
- 继续后，工具打开目标工作簿并比较登记快照与当前单元格；如内容不同，会显示两边内容并要求您选择。只有目标位置成功定位并完成确认后，事项路径才会更新；取消或定位失败不会更改旧记录。
- 如果工作表被删除或重命名，会提示找不到工作表，不会静默定位到错误位置。

### 变更历史

右键事项 → **变更历史…**，或在详情中点击“变更历史”，可以查看登记、状态、项目、内容快照、文件路径、缺失资料、备注等变更的前后值。

## 5. 更新状态和补充资料

选中一行后：

- 右键 → **标记状态**，选择“未完成 / 等待资料 / 进行中 / 已完成”；多选时会批量应用；
- 或点击“编辑详情”（`Ctrl+E`），在详情窗口修改状态、项目、缺失资料、负责人、索取/收到日期、备注，然后保存；
- 清单详情预览区可用 **“快速跟进…”** 只编辑缺失资料、负责人、索取/收到日期和状态；“资料已收到…”会预填今天日期，保存前仍可手动选择状态；
- 或按 **`Ctrl+Shift+D`** 快速标记为“已完成”。

状态只能由您手动修改。工具不会因为单元格内容变化而自动把事项标为完成。  
“收到日期”只是记录，不会自动改变状态；是否完成仍由您判断。

### 项目归档

工具栏“项目归档”或设置中的“项目归档管理…”可以：

- 查看各项目的事项数；
- 归档/取消归档项目；
- 查看某个已归档项目的全部事项。

归档只影响清单默认显示，不会删除事项。

## 6. 快捷键一览

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+M` | 在 Excel/WPS 中登记当前单元格（全局热键，可自定义） |
| `Ctrl+L` | 定位选中的事项（需单选） |
| `Ctrl+E` | 编辑选中的事项（需单选） |
| `Ctrl+Shift+D` | 把选中事项标记为“已完成”（可多选） |
| `Ctrl+A` | 全选当前清单 |
| `F5` | 刷新清单 |
| 双击清单行 | 定位底稿 |

热键可以在“设置”中更换。若热键与其他软件冲突，程序会提示注册失败。

## 7. 数据保存在哪里

默认目录：

```
%LOCALAPPDATA%\WorkpaperTodo\
```

其中：

- `data.db`：事项数据（SQLite，明文）；
- `config.json`：热键、当前项目、筛选、窗口位置等设置；
- `app.log`：本地运行日志；自动轮转，绝对路径会脱敏，但仍可能包含文件名或错误信息，请按客户资料要求保管；
- `backups\`：手动备份和每日自动备份；
- `practice\`：首次引导中按用户点击生成的合成练习工作簿；如文件名已存在会生成新文件，不覆盖；
- `location.txt`（仅当更改过数据目录）：指向自定义数据目录。

### 自动备份

默认每天首次启动时自动备份到 `backups\auto-*.db`，保留最近 7 份。可在“设置”中关闭或调整保留数量（配置文件键 `auto_backup_keep`）。

### 普通备份和加密备份

- “设置” → **普通备份…**：生成一份普通 SQLite 数据库副本。
- “设置” → **加密备份…**：使用 Windows DPAPI 当前用户密钥加密，生成 `.enc` 文件。
- “设置” → **解密备份…**：解密到指定 `.db` 文件，并做 SQLite 完整性检查；如需恢复，请退出程序后用该文件替换数据目录中的 `data.db`。

加密备份只能由**同一台电脑、同一 Windows 用户**解密；换电脑或换 Windows 用户无法恢复。请同时保留普通备份。

### 更改数据目录

“设置” → **更改数据目录…**：

- 如果目标目录为空，会把当前 `data.db`、`config.json` 和 `backups` 复制过去，原目录保留；
- 如果目标目录已有 `data.db`，会询问是否切换到该目录的现有数据，不会覆盖；
- 更改后需要退出并重新启动程序。

### 导出

工具栏 **“导出 ▾”** 提供：

- **导出 CSV**：全部事项，UTF-8 带 BOM，Excel/WPS 可直接打开；部分以 `=`、`+`、`-`、`@` 开头的文本会加英文单引号，避免被当成公式；
- **导出 Excel 复核清单**：生成带格式和“打开文件”链接的 `.xlsx`，包含状态、项目、程序、缺失资料、负责人、日期、等待天数、备注和完成时间；
- **导出 HTML 复核清单**：生成可在浏览器打开的清单，同样包含打开文件的链接。
  链接只打开文件，精确位置请使用“定位底稿”。

### 日志

“设置” → **打开日志文件夹** / **清空日志**。清空日志不会影响事项数据。

### 安全说明

- 所有数据只保存在本机，工具**不会上传**底稿、单元格内容或清单。
- 工具**不向原底稿写入**任何标记、批注或内容，也**不会自动保存**原底稿。
- `data.db` 是本地明文 SQLite 文件，里面会包含审计程序文字和文件路径。请按事务所对客户资料的要求保管，不要把数据目录随意共享或上传网盘。
- 加密备份仍受 Windows 用户账户和电脑安全影响；它不是替代事务所资料管理制度的方案。
- 测试或演示时请使用自行创建的测试底稿，不要使用真实客户资料。

## 8. 已知限制

1. 当前版本面向 **64 位 Windows**；Windows 10、32 位 Office/WPS 未独立验证。
2. 只支持 **单个单元格或一个合并单元格**；一次选择多个单元格或多个合并区域会被拒绝。
3. 只支持**已经保存到本机或共享文件夹**的工作簿；未保存的新工作簿、云文档链接不支持。
4. 程序被移动到另一个单元格时，工具不会自动跟随；如果原位置的内容与快照不同，会提示人工确认。即使文字相同，也不能仅凭快照保证文件版本和程序位置完全正确，请结合底稿核对。
5. 文件指纹只是辅助线索：同一磁盘内移动/改名通常保留，复制文件会生成新指纹；不能把它当作绝对身份证明。
6. 工作表隐藏、保护，或 Excel/WPS 正在弹窗/编辑时，读取或定位可能失败，工具会给出提示。
7. 支持本机单人使用，不含多人协作、云同步、账号权限。
8. 工具不替代审计准则对工作底稿的要求；是否完成审计程序、是否取得充分适当的审计证据，仍由项目组判断并在底稿中记录（参见《中国注册会计师审计准则第 1131 号——审计底稿》）。
9. 热键是全局的，程序运行期间会占用该组合键；如与其他软件冲突，请在“设置”中更换。
10. 关闭主窗口默认进入托盘；如果托盘图标不可用，关闭窗口会直接退出。
11. 当前主显示器 150% 缩放下已验证主窗口和首次引导完整显示；全部对话框另用 Tk scaling 模拟 125%/150% 检查，窗口能放入屏幕。真实混合 DPI 缩放、受保护视图、密码文件、OneDrive/网络共享等环境仍需按事务所实际环境补测。
12. 当前交付 exe 未使用受信任证书签名，Windows SmartScreen 可能提示“未知发布者”；已提供签名脚本，但当前环境没有受信任证书，正式分发前需要补齐。

## 9. 常见问题

**关闭窗口后热键还能用吗**

- 默认可以。关闭主窗口会最小化到托盘，热键和后台登记继续工作。
- 右键托盘图标 → “退出”才会真正结束程序。
- 如果托盘不可用，关闭窗口会直接退出。

**按热键没有反应**

- 确认“底稿未完成助手”正在运行（托盘中有图标）；
- 到“设置”确认热键已成功注册；如果提示被占用，换一个组合键；
- 确认当前激活的是 Excel/WPS 表格窗口，而不是浏览器、Word 或其他程序。

**提示“无法读取当前单元格”**

- 按 `Esc` 退出单元格编辑状态；
- 关闭 Excel/WPS 中的对话框（如“查找”“格式单元格”）；
- 确认选中的是一个单元格，而不是图表或多个单元格；
- 重试；如果仍失败，重启 Excel/WPS 后再试。

**点击定位后提示“未检测到对应的表格窗口”**

- 文件可能被密码、文件占用或“受保护的视图”阻止；
- 手动打开文件，确认没有弹窗，再回到清单点击“定位底稿”。

**托盘图标找不到**

- 点击任务栏右下角的“^”展开隐藏图标，把本工具图标拖到常驻区域；
- 如果仍找不到，到“设置”取消“关闭主窗口时最小化到托盘”，关闭窗口会直接退出，不会留在后台。

**加密备份换电脑后打不开**

- 这是 DPAPI 用户级加密的设计限制，只能在同一台电脑、同一 Windows 用户下解密。请保留普通备份，或在新电脑重新做加密备份。

**换电脑/重装后数据还在吗**

- `data.db` 在 `%LOCALAPPDATA%\WorkpaperTodo\`；拷贝该文件到新电脑相同目录即可（先退出程序）。
- 如果更改过数据目录，请同时拷贝 `location.txt` 指向的目录。

## 10. 卸载

使用发布包中的 `卸载.bat` / `uninstall_per_user.ps1`，或开始菜单中的“卸载底稿未完成助手”（Inno 安装包也可从 Windows“设置 → 应用”卸载）：

1. 退出程序（托盘菜单 → 退出）；
2. 运行卸载脚本或开始菜单卸载项，删除程序目录和开始菜单快捷方式；
3. 默认保留数据目录；如确认不再需要，运行 `uninstall_per_user.ps1 -RemoveData` 删除 `%LOCALAPPDATA%\WorkpaperTodo`。

手动安装的绿色版可以直接删除程序文件夹；数据目录同上。
